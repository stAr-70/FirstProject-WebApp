# 🏋️‍♂️ Gym Management System

> **📅 Project Timeline:** 
> Developed in **July 2025** as my first hands-on project, uploaded here to document my software engineering journey and backend logic implementation.

---

## 📌 About The Project
A functional web application focused on backend operations for managing gym registrations. The project emphasizes data processing, reporting, and automated email operations rather than frontend UI design.

---

## ✨ Core Functionalities & Operations
* 📝 **Member Registration:** Handles student/member enrollment and service selection into the database.
* 📊 **Data Retrieval & Management:** Queries and displays registered user data for administrative overview.
* 📁 **Excel Data Export:** Processes and exports stored database records into Excel spreadsheets.
* ✉️ **SMTP Email Integration:** Executes backend email triggers to facilitate direct communication with gym management.

---

## 🛠️ Tech Stack
* **Framework & Language:** ASP.NET Web Forms / C#
* **Database:** SQL Server
